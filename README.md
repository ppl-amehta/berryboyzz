## 🍓 Executive Overview

**Berryboyzz** is a precision horticulture and controlled-environment agriculture (CEA) enterprise cultivating elite Primocane berry genetics. The digital flagship combines Apple Pro-grade vertical scroll-linked morphogenesis storytelling with verifiable institutional agro-asset economics, powered by an autonomous dual-engine SLM intelligence agent (**Dr. Berryboy**).

### Key Pillars:
1. **Procedural Morphogenesis Canvas:** A continuous 60/120fps Canvas2D engine tracking a berry from embryonic seed ($0.4\text{g}$) to rhizosphere rooting, vegetative canopy, floral blooming, anthocyanin ripening ($14.2^\circ\text{ Brix}$), and luxury $125\text{g}$ cold-chain table punnet presentation.
2. **The 5 Flagship Cultivars:** Raspberry, Blackberry, Mulberry (Shahtoot), Strawberry, and Blueberry with botanical dossiers, yield curves, and gourmet pairing recipes.
3. **Turnkey CEA Engineering:** 5 commercial cultivation systems across Pune & Satara (Naturally Ventilated Polyhouse, Walk-in Polytunnels, Substrate Grow-Bags, Automated IoT, Urban Rooftops).
4. **The 4-Tier Investment Ladder:** On-ramps scaling from Balcony Proof-of-Concept kits ($\text{₹}2,999$) to the flagship **50-Acre $\text{₹}40,000,000$ ($\text{₹}4\text{Cr}$) Institutional Agro-Asset Syndicate**.

## 🛠️ Tech Stack & Architecture

- **Core Framework:** SvelteKit 3.1.1 + Svelte 5 Runes (`$state`, `$derived`, `$props`)
- **Compilation & Bundling:** Vite 8.3.5 with native **Rolldown** Rust bundler
- **Language & Type System:** TypeScript 7.0.2 native Go compiler (`tsgo`) & TypeScript 6.0.3 tooling
- **Styling & Layout:** Tailwind CSS v4.3.4 + Glassmorphic Obsidian Design System
- **Subpath Package Architecture:** Pure Node.js native package imports (`#components/*`, `#data/*`, `#types/*`, `#utils/*`, `#services/*`, `#lib/*`)
- **Testing:** Vitest 5.1.0 automated test matrix (68 tests across 12 suites)
- **Deployment & Edge CDN:** Vercel Edge & Serverless Runtime (`bom1` Mumbai region) with continuous GitHub Actions orchestration
- **Meta Platform Integration:** Meta Graph API `v26.0` (WhatsApp Cloud API, Instagram Graph API, System User Token Manager)

## 🚀 Quick Start & Development

```bash
# Clone the repository
git clone https://github.com/ppl-amehta/berryboyzz.git
cd berryboyzz

# Install dependencies deterministically
npm ci

# Start local development server
npm run dev

# Run strict typecheck and type manifest generation
npm run check

# Run automated verification test matrix (68 tests)
npm test

# Compile production bundle with Vite 8 Rolldown
npm run build

# Run Meta Apex Control CLI
npm run meta:cli -- audit
```

## 🧪 CI/CD Quality Gate

On every commit to `main` and all pull requests, the `.github/workflows/deploy.yml` pipeline enforces:
1. **TypeCheck & Manifest Verification:** `npm run check` (`svelte-kit sync` + `tsc --noEmit`).
2. **Vitest Automated Test Matrix:** 100% test pass rate across all 68 unit, agronomic, API, and webhook integration suites.
3. **Production Compilation:** `npm run build` using Rolldown SSR + Prerendering + `@sveltejs/adapter-vercel`.
4. **Traceable DevOps Deployment:** Continuous Vercel deployment synced with verified GitHub commits.
